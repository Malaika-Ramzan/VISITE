## 🚀 Features

- ✅ Smooth Scroll - Makhan jaisa smooth scrolling
- ✅ Parallax Effect - Photo aahista hilti hai, text tez aata hai
- ✅ Side Dots Navigation - 4 dots se kisi bhi section par jayein
- ✅ Fully Responsive - Mobile, iPad, Laptop & PC sab me perfect
- ✅ Mobile Menu - Mobile me ☰ wala menu
- ✅ Beautiful UI - Modern, Clean & Elegant Design
- ✅ Fast Loading - No heavy libraries, only pure code
